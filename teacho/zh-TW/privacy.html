隱私權政策

2026-11-02 · 拾茶 / Teacho · YUTAI WANG

照片與權限

無需帳號。照片處理與對比圖製作在裝置上完成，不上傳照片，不修改或刪除原始照片。經你操作儲存的對比圖會作為新圖片寫入相簿；iCloud 照片由系統下載。可在系統設定中撤銷照片、相機及通知權限。

回憶提醒

開啟每日提醒後，Teacho 會在裝置上分析少量照片縮圖，辨識貓、花、風景等場景，用於產生回憶通知。裝置上的語言模型可用時，會根據場景標籤潤飾文案；無法使用時則採用預設文案。照片和場景標籤不會因此上傳至伺服器，也不會使用雲端模型。

通知文案及用於重複使用文案的照片識別碼、修改時間等資訊會快取在本機，過期日期的快取會被清除。場景文案可能出現在鎖定畫面通知中，你可以在系統通知設定中管理預覽。

Firebase

Teacho 使用 Google Firebase Analytics 瞭解應用程式的使用情況，使用 Crashlytics 發現和排查當機。這些服務可能向 Google 傳送應用程式執行個體識別碼、使用事件、應用程式及系統版本、裝置資訊、當機堆疊等統計與診斷資料。我們未啟用廣告識別碼（IDFA）收集，並關閉了廠商識別碼（IDFV）收集及預設廣告個人化信號。照片、照片識別碼、場景標籤和產生的回憶文案不會作為自訂統計或當機記錄上傳。

統計與診斷補充

Firebase Analytics 也會透過 IP 位址推導大致位置，並記錄應用程式啟動、頁面及工作階段等事件。當機與工作階段診斷可能包括效能及其他診斷中繼資料。統計和診斷可與應用程式執行個體或安裝識別碼關聯；我們不將這些資訊用於跨應用程式廣告追蹤。

本機資料與聯絡

提醒設定及文案快取儲存在本機。你可以關閉提醒、撤銷權限或刪除應用程式來清除應用程式本機資料；系統相簿中的圖片需透過相簿管理。主動寄信聯絡時，我們會處理你提供的信箱與問題內容以回覆支援請求。有關資料請求，請聯絡 realsidney@qq.com。

網站與第三方

本網站由 GitHub Pages 託管，服務提供者可能處理 IP 位址等存取記錄。本頁面沒有加入使用統計或廣告指令碼。Google 對統計與診斷資料的處理、儲存與安全說明請見下方連結。政策會隨功能與資料處理方式變更更新。

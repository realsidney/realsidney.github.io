隐私政策

2026-11-02 · 拾茶 / Teacho · YUTAI WANG

照片与权限

无需账号。照片处理与对比图制作在设备上完成，不上传照片，不修改或删除原始照片。经你操作保存的对比图会作为新图片写入相册；iCloud 照片由系统下载。可在系统设置中撤销照片、相机及通知权限。

回忆提醒

开启每日提醒后，Teacho 会在设备上分析少量照片缩略图，识别猫、花、风景等场景，用于生成回忆通知。设备上的语言模型可用时，会根据场景标签润色文案；不可用时使用预设文案。照片和场景标签不会为此上传至服务器，也不会使用云端模型。

通知文案及用于复用文案的照片标识、修改时间等信息会缓存在本机，过期日期的缓存会被清理。场景文案可能出现在锁屏通知中，你可以在系统通知设置中管理预览。

Firebase

Teacho 使用 Google Firebase Analytics 了解应用的使用情况，使用 Crashlytics 发现和排查崩溃。这些服务可能向 Google 发送应用实例标识、使用事件、应用及系统版本、设备信息、崩溃堆栈等统计与诊断数据。我们未启用广告标识符（IDFA）收集，并关闭了供应商标识符（IDFV）收集及默认广告个性化信号。照片、照片标识、场景标签和生成的回忆文案不会作为自定义统计或崩溃日志上传。

统计与诊断补充

Firebase Analytics 还会通过 IP 地址推导大致位置，并记录应用启动、页面及会话等事件。崩溃与会话诊断可能包括性能及其他诊断元数据。统计和诊断可与应用实例或安装标识关联；我们不将这些信息用于跨应用广告跟踪。

本地数据与联系

提醒设置及文案缓存保存在本机。你可以关闭提醒、撤销权限或删除应用来清除应用本地数据；系统相册中的图片需通过相册管理。主动邮件联系时，我们会处理你提供的邮箱和问题内容以回复支持请求。有关数据请求，请联系 realsidney@qq.com。

网站与第三方

本网站由 GitHub Pages 托管，服务提供方可能处理 IP 地址等访问日志。本页面没有添加使用统计或广告脚本。Google 对统计与诊断数据的处理、保存与安全说明见下方链接。政策会随功能与数据处理方式变化更新。
